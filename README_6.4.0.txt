NetworkAutomation UI 6.4.0

Focus: functional reliability.

New:
- Persistent machine Online/Offline/Unknown state.
- Last seen / offline since / missed-check counter.
- Device presence transition history on Dashboard.
- One-miss hysteresis to reduce false Offline reports.
- Identity Guard for one MAC observed on multiple IP addresses.
- Extended Function Audit checks.

Upgrade:
1. Extract the ZIP.
2. Right-click ONECLICK_UPDATE.bat and choose Run as administrator.
3. Open the Dashboard and press "Kiem tra lai" once.
4. Review Quan tri > Kiem tra chuc nang.

Existing database, credentials and inventory are preserved by the normal upgrade workflow.
